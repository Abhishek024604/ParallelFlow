---

# Progress entry

Write three to six bullets of plain facts from the request and the conversation:

- stage moves and gate outcomes (who approved, when);
- documents created or updated (name and version);
- work finished or started (by whom);
- anything blocking.

No opinions, no plans, no ids or tool names. If nothing changed, write "No changes in this window." Call no tool that changes anything.
